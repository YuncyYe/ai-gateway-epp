# 场景说明：SC03 主备角色切换

所属场景编号：SC03；代码目录：`test/implementation/scenario-SC03-assignment-role-switch`（包名 `sc03`）。

## 1. 背景与目的

验证 assignment 驱动的主备角色生命周期：降备（primary→standby）后 ext-proc 拒绝服务（gRPC `Unavailable` + "cell is not serving"）；提升（standby→primary）后恢复服务；摘除后 cell 被删除、上报中消失，其余 cluster 不受影响。

观测手段：ext-proc 错误语义、assignment report（POST `/configs/epp_data/assignment/report`）中 `cells[].key/role/state`。

## 2. 运行模式

同 SC01（单组件进程组，每 TC 独立一套）。

## 3. 配置构造

- assignment 按 TC 演进：`{"cluster-a": "primary"}` → `standby` → `primary`（或摘除）
- picker_config / cluster_table：同 SC01 最小配置

## 4. TC 列表

| 编号 | 名称 | 断言要点 |
|---|---|---|
| TC-01 | 降备拒绝服务 | SetAssignment standby → 轮询至 pick 返回 `not serving` 错误；liveness 仍 SERVING |
| TC-02 | 提升恢复服务 | standby 拒绝后再提升 primary → pick 恢复成功；report 中 `role=primary, state=primary` |
| TC-03 | 摘除去 cell | 从 assignment 移除 cluster-a（保留 cluster-b）→ cluster-a pick 失败、cluster-b 正常；report 不再携带 cluster-a |

## 5. 依赖与就绪

同 SC01 §5。角色变化经 assignment 轮询（200ms）生效，观察窗口 20s。
