# 场景说明：SC04 InnerAPI 故障 fail-static

所属场景编号：SC04；代码目录：`test/implementation/scenario-SC04-innerapi-failure`（包名 `sc04`）。

## 1. 背景与目的

验证 ai-gateway-api 不可用时 epp 的 fail-static 行为：调度继续基于最后同步状态工作（进程不退出、liveness 正常）；故障期间下发的配置在恢复后自动追平。

观测手段：故障期间的 pick 成功率、`ai_epp_engine_current_version` 哈希在恢复后的变化。

## 2. 运行模式

同 SC01（单组件进程组，每 TC 独立一套）。mock 提供 `SetFail(true)` 使全部版本化端点返回 500。

## 3. 配置构造

- epp_data/config（epp_config + assignment 全量视图）与 cluster_table：同 SC01 最小配置
- TC-02 在故障窗口内下发 v2 配置（插件重命名），恢复后观察哈希追平

## 4. TC 列表

| 编号 | 名称 | 断言要点 |
|---|---|---|
| TC-01 | 故障期 fail-static | SetFail(true) → pick 仍成功命中 sim；liveness SERVING |
| TC-02 | 恢复后追平 | 故障期间下发 v2 → 哈希保持 v1 → SetFail(false) → 哈希变为 v2、调度正常 |

## 5. 依赖与就绪

同 SC01 §5。
