# 场景说明：SC08 cluster 数据驱动生命周期

所属场景编号：SC08；代码目录：`test/implementation/scenario-SC08-cluster-lifecycle`（包名 `sc08`）。

## 1. 背景与目的

验证 cluster 生命周期的**数据驱动**特性（需求分析 FR-D4、FR-M3、FR-C2）：

- 运行中的 epp 在 assignment / picker_config / cluster_table 三视图同时出现一个新 cluster 后，自动完成建 cell、编译引擎、发现端点、对外服务，全程无重启；
- picker_config 中出现本实例**未分配**的 cluster 配置时，不建 cell、不进入上报、不影响已分配 cluster（配置隔离）。

## 2. 运行模式

同 SC01（单组件进程组，每 TC 独立一套）。

## 3. TC 列表

| 编号 | 名称 | 断言要点 |
|---|---|---|
| TC-01 | 新 cluster 动态纳入 | 起 cluster-a 后加入 cluster-b（新 sim + 三视图全量更新）：cluster-b 可调度且命中新 sim、cluster-a 不受影响；上报出现 cluster-b cell |
| TC-02 | 未分配配置隔离 | picker_config 增加 cluster-ghost（assignment 未分配）：等待多个轮询周期后无 cluster-ghost 引擎、上报不含它；cluster-a 服务正常 |

## 4. 依赖与就绪

同 SC01 §5。新 cluster 纳入涉及三个 poller 的时序，观察窗口 30s。
