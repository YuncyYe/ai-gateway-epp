# TC-02 环境变量启用本地模式

| 项 | 内容 |
|---|---|
| 用例编号 / 名称 | TC-02 / 环境变量启用本地模式 |
| 所属场景 | SC15 本地配置文件加载 |
| 版本 | v0.1 |

## 测试目的

验证 `AI_GATEWAY_EPP_LOCAL_CONFIG_DIR` 环境变量与 `--local-config-dir` 参数等价：仅通过环境变量即可进入本地文件加载模式并完成闭环。

## 运行模式

同 TC-01（epp 真实进程 ×1，无 mock/sim）。对应实现（拟）`TestTC02_LocalConfigEnvVar`（env 标识 `epp-sc15-tc02`）。

## 前置条件

1. 同 TC-01 的三份本地配置文件。
2. epp 启动时 **不传** `--local-config-dir`，改为在子进程环境中设置 `AI_GATEWAY_EPP_LOCAL_CONFIG_DIR=<dir>`（`cmd/epp/config.go` 中 flag 默认值取自该环境变量）。

## 测试步骤

| # | 操作 | 预期 |
|---|---|---|
| 1 | 以环境变量方式启动 epp，等待 gRPC 监听 | 进程监听成功 |
| 2 | `WaitHealth("", 30s)` | readiness SERVING |
| 3 | 抓取 `/metrics`：`ai_epp_engine_current_version{cluster="cluster-a"}` 非空、`cell_state{...role="primary",state="primary"}`=1、`assignment_no_match`=0 | 本地配置加载生效，行为与 `--local-config-dir` 一致 |
| 4 | ext-proc pick cluster-a | 返回 `127.0.0.1:portA` |

## 预期结果

- 环境变量方式与命令行参数方式行为一致，readiness/引擎/cell/端点均正确。
- 说明：本 TC 需为子进程注入环境变量，harness 需支持 `StartProcessWithEnv`（计划新增）。

## 清理

`defer e.Close()`。
